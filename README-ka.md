# დოკუმენტების ასისტენტი — ინსტრუქცია

## გაშვება Windows-ზე

1. ორჯერ დააწკაპუნეთ ფაილზე **`A:\Rag_Test\start.bat`**.
2. ბრაუზერში გაიხსნება **http://127.0.0.1:8765** (თუ არ გაიხსნა, ჩაწერეთ ეს მისამართი ხელით).
3. გასაჩერებლად დახურეთ შავი ფანჯარა (ან დააჭირეთ Ctrl+C).

პირველ გაშვებაზე პროგრამა თავად შექმნის Python-ის გარემოს და შემოიტანს ბიბლიოთეკას (ინტერნეტი საჭიროა მხოლოდ პაკეტების ჩამოსატვირთად).

## OpenAI გასაღების ჩაწერა

1. გახსენით ფაილი **`A:\Rag_Test\.env`** Notepad-ით (მარჯვენა ღილაკი → Open with → Notepad).
2. ხაზში `OPENAI_API_KEY=` ტოლობის ნიშნის შემდეგ ჩასვით გასაღები (`sk-...`), ჰარის და ბრჭყალების გარეშე.
3. შეინახეთ. აპლიკაციაში: **„ინდექსი“ → „OpenAI-ის შემოწმება“**. გადატვირთვა საჭირო არ არის.
4. იქვე: **„ხარჯის შეფასება“** → **„ინდექსირების დაწყება“** (ერთჯერადად ≈ $0.10).

გასაღები მხოლოდ თქვენს კომპიუტერზე, სერვერის მხარეს ინახება; ბრაუზერში და ჟურნალებში არ ჩანს.

## გამოყენება

- დასვით კითხვა ქართულად. პასუხი ეტაპობრივად გამოჩნდება; ქვემოთ — წყაროების ბარათები.
- ბარათზე: **„ამონარიდი“** (ზუსტი ტექსტი და სტატუსი), **„გვერდი“** (გვერდის გამოსახულება).
- ლურჯი `[07-c0058]` = დადასტურებული მითითება; წითელი `⚠` = მითითება, რომელიც მოძიებულ წყაროებში არ იყო.
- მარცხნივ მონიშნეთ დოკუმენტები, თუ გინდათ ძიება მხოლოდ მათში.
- „ახალი საუბარი“ — ახალი თემა; სხვა შემთხვევაში შემდგომი კითხვები წინა კონტექსტს ითვალისწინებს.
- „ხარჯები“ ჩანართში — დახარჯული ტოკენები და მიახლოებითი თანხა. ზუსტი თანხა: OpenAI-ის Usage გვერდი.

## ახალი დოკუმენტების დამატება (იმავე ფორმატით)

ახალი დოკუმენტები უნდა იყოს მომზადებული იმავე სტრუქტურის პაკეტად (`manifest.json`, `index/native-chunks.jsonl`, `documents/ID/...`).

1. გაშალეთ პაკეტი ცალკე საქაღალდეში, მაგ. `A:\Rag_Test\data\library-2\`.
2. გახსენით PowerShell საქაღალდეში `A:\Rag_Test` და გაუშვით:
   ```
   .venv\Scripts\python -m app.cli import --library data\library-2 --library-id library-2 --id-prefix B-
   ```
   `--id-prefix` საჭიროა, თუ ახალ პაკეტში დოკუმენტების ნომრები (01, 02…) ემთხვევა არსებულს.
3. აპლიკაციაში: „ინდექსი“ → „ხარჯის შეფასება“ → „ინდექსირების დაწყება“ (დამუშავდება მხოლოდ ახალი ჩანაწერები).

იმავე პაკეტის განახლებული ვერსიისთვის: ჩაანაცვლეთ საქაღალდე და დააჭირეთ „ბიბლიოთეკის ხელახალი იმპორტი“ — შეცვლილი ჩანაწერები ჰეშებით ამოიცნობა, დუბლიკატები არ იქმნება.

## მოდელის შეცვლა

`.env`-ში შეცვალეთ `OPENAI_CHAT_MODEL` ან `OPENAI_EMBEDDING_MODEL`. embeddings მოდელის შეცვლისას ძველი ვექტორები არ აირევა ახლებთან — საჭიროა ხელახალი ინდექსირება ახალი მოდელით.
